# Simple Voice Chat / Installation
> Das folgende Tutorial ist für die Simple Voice Chat Plugin Version für Server.

## Step 1 - Auf dem Server installieren
1. Lade von Modrinth oder CurseForge die `.jar` Datei herunter.

2. **Auf Fabric:** Gehe in den `mods` Ordner und füge die Datei ein.<br><br>
**Auf Paper:** Gehe in den `plugins` Ordner und füge die Datei ein.

3. Starte den Server neu.
