# Simple Voice Chat
Simple Voice Chat, kurz SVC ist ein kostenloses und das meistgenutzte Plugin und Mod für die Proximity Voice Chats. Mit SVC kann man mit anderen Leuten im Spiel reden, Gruppen und private Gruppen erstellen, uvm.
