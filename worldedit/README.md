# WorldEdit
WorldEdit ist ein kostenloses und eins der meistgenutzten Plugins für die Weltenerstellung. Mit WorldEdit kann man viele, große und aufwendige Gebäude, Landschaften und viel mehr einfach und schnell erstellen. WorldEdit hat auch einige Forks wie FastAsyncWorldEdit und funktioniert perfekt mit WorldGuard.
